---

## 一、背景

电脑版「工作流工具台」已完成并通过验证（Web 应用，Node.js 后端 + 浏览器界面，支持工作流/环节/状态/置顶/备份/流程链路图）。

现在要把它装进手机，成为 **APK**，并通过 GitHub Actions 自动编译，让后续迭代不用手动打包。

---

## 二、用户故事

### US-1 在手机上使用我的工作流
> 作为一个用户，我希望在手机上打开 APP，就能看到我电脑上建的「让生活幸福的工作流」，并且能改状态、加环节。

**验收标准**
- 手机连同一个 WiFi，填写电脑地址后，能看到电脑上的全部工作流
- 手机上改状态，电脑端刷新后能看到（反之亦然）
- 断网/不在家时，APP 不崩溃，给出明确提示

### US-2 出门也能用
> 作为一个用户，我出门在外（连不上电脑）时，也想查看和修改我的工作流。

**验收标准**
- APP 内置「离线模式」，数据存手机本地
- 离线时能完整增删改查
- 回到家用「连电脑模式」，数据不丢

### US-3 数据不丢
> 作为用户，我怕手机丢了/APP 卸载了，数据全没了。

**验收标准**
- 能导出备份文件到手机存储
- 能导入备份文件恢复
- 至少一个自动备份机制

### US-4 自动编译 APK
> 作为开发者，我改完代码推送到 GitHub，希望能自动产出 APK，不用装 Android SDK。

**验收标准**
- 推送到 main 分支 → 自动编译
- 打 tag（v*）→ 自动编译 + 创建 Release + 上传 APK
- 能在 GitHub Actions 页面下载 APK 产物

## 三、功能范围

### 3.1 必须做（P0）

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 内嵌界面 | APK 内包含完整前端，无需联网也能显示界面 |
| F2 | 服务器地址配置 | 设置页填写电脑 IP:端口，一键测试连接 |
| F3 | 双模式数据层 | 连电脑模式（走 HTTP）/ 离线模式（走本地存储） |
| F4 | 本地数据持久化 | 离线模式数据存手机，关 APP 不丢 |
| F5 | 备份导出/导入 | 手机文件系统读写 |
| F6 | 局域网发现（可选降级） | 自动扫描或手动输入 |
| F7 | GitHub Actions CI | 自动编译 APK |

### 3.2 暂不做（P1/P2）

| 功能 | 原因 |
|---|---|
| 云同步 | 涉及服务器成本，先靠「连电脑模式 + 手动备份」 |
| 多设备实时同步 | 复杂度高，局域网轮询够用 |
| 账号系统 | 个人工具，不需要 |
| iOS | 只做 Android |
| 应用商店上架 | 自用，直接装 APK |

## 五、成功标准

1. 手机安装 APK 后，**不配置任何东西**就能新建工作流（离线模式）
2. 填入电脑地址并测试通过后，**能看到电脑上的数据**
3. 手机改一个环节状态，**电脑刷新后同步可见**
4. 推送到 GitHub 后，**Actions 自动产出 APK 下载链接**
5. 全程**不需要在本地安装 Android SDK**

## 六、约束与风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 局域网 IP 会变 | 手机连不上电脑 | 电脑启动时打印当前 IP；APP 里可改 |
| 电脑没开机 | 连电脑模式失效 | 离线模式兜底；提示切换 |
| 手机浏览器/WebView 兼容性 | 界面错乱 | 用 Android 系统 WebView，已做响应式 |
| GitHub Actions 免费额度 | 构建排队慢 | 用公开仓库，缓存 Gradle |
| 本机 npm 装 Capacitor 慢 | 首次搭建耗时 | 用 npmmirror 镜像 |
